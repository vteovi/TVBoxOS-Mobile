## 生成 build_apk.bat 一键编译脚本
- 位置：项目根 `D:\GitHub\TVBoxOS-Mobile\build_apk.bat`（纯 ASCII + CRLF，按 robust-windows-bat-launcher 规范）。
- 用法：双击运行 → `choice` 菜单选 1=Debug / 2=Release；或命令行 `build_apk.bat debug|release` 跳过菜单。
- 内置：`JAVA_HOME=C:\Java\jdk-17`、`ANDROID_HOME=C:\Android\Sdk`、`cd /d %~dp0`、`call gradlew.bat assemble{Debug,Release} --console=plain`。
- 构建完自动定位 `%OUTDIR%` 最新 APK（`dir /b /o-d` + for /f 取值），打印完整路径、字节数和 adb install 命令。
- 版本号解析：`findstr /r /c:"^ *versionName *'"` —— **必须带行首锚定正则**，否则会匹配到 `outputFileName = ... variant.versionName ...` 行（tokens=2 取到 `=`）。测试时发现并修复。
- 校验：python 静态检查（非 ASCII=0、全 CRLF、括号配平、无块内标签）+ 临时目录桩替换实测（成功路径打印 BUILD SUCCESS+APK 路径；失败路径 `cmd /c exit 1` 模拟 errorlevel 打印 BUILD FAILED）双通过。
- 注意：测试桩不能用 `exit /b 1`（会退出整个脚本而非返回 errorlevel），要用 `cmd /c exit 1`。
