## 详情页新增"外部播放"按钮（调用第三方播放器）
- 用户原话"播放页面"实为**详情页** `activity_detail.xml`（"加入收藏" tvCollect 在此，播放页控制条并无收藏按钮）。
- 在 `tvCollect`(收藏) 左边新增 `tvExternalPlay`(外部播放) TextView，图标 `ic_external_play_18.xml`(新矢量，open-in-new 风格，18dp，tint=text_foreground)。
- 点击 `showExternalPlayerChooser()`：用 `PlayerHelper.getExistPlayerTypes()` 取已安装第三方播放器(类型 10=MX 11=Reex 12=Kodi 13=附近TVBox 14=VLC)；无则 toast 提示；多个则用 XPopup `asCenterList` 选择；选定后调 `playFragment.playExternal(type)`。
- `PlayFragment.playExternal(int)`：复用 `PlayerHelper.runExternalPlayer(type, activity, url, title, subtitle, headers, progress)`；url 优先用 `getFinalUrl()`(预览已解析地址)，否则退回当前集原始地址 `vs.url`(直链源可直接播，解析源需先播预览)；`playFragment==null`(预览关闭)时提示开启预览。

- 注意：`playFragment` 仅在 `showPreview`(默认 true) 时创建，预览关闭者无法外部播放。

## 修复"外部播放"检测不到播放器（用户实测点外部播放报"未检测到可用的第三方播放器"）
- 根因①：原来只把 type≥10 当"外部播放器"，type 0(系统播放器) 在 `getPlayersExistInfo()` 被硬编码 `false` 且选择器过滤 `t>=10` 排除 → 系统播放器选项根本不出现、列表为空就报"未检测到"。
- 根因②：`MXPlayer.getPackageInfo()` 只查 `.pro`/`.ad` 两个包名，用户装的 beta/其它变体检测不到。
- 修复：
  - `PlayerHelper`：type 0 改为"系统是否装有能处理 video/* 的应用"的真实检测；新增 `runSystemPlayer()` 用 `ACTION_VIEW`+`video/*`+`Intent.createChooser` 拉起系统"用以下应用打开"面板（系统播放器/MX/VLC 全列出，等同"打开视频文件"）；`runExternalPlayer` 增加 `case 0` 调用它。
  - `DetailActivity.showExternalPlayerChooser`：可选列表纳入 type 0，提示文案改为"未检测到可用的播放器"。
  - `MXPlayer`：增加 `com.mxtech.videoplayer.beta` 包名检测，直连 MX 快捷键覆盖更多版本。
- 注意：`ACTION_VIEW` 无法携带自定义 HTTP 头(Referer/UA)，需鉴权的直链走系统播放器可能失败——这是系统限制，非 bug。
