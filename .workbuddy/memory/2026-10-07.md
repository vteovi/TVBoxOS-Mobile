## 诊断：详情页"暂无数据"（首页点海报，龙门影视订阅源）
- 现象：使用龙门影视订阅源，首页能显示海报，但点海报打开详情页显示 LoadSir 空布局"暂无数据"（loadsir_empty_layout.xml）。
- 触发链：GridFragment 点海报 → bundle(id, sourceKey) → DetailActivity.loadDetail → SourceViewModel.getDetail(sourceKey,id) → 按 SourceBean.type 走 spider(type3)/OkGo(type0,1,4) → json/xml 解析 → checkThunder → postValue → observer 判 `movie.videoList` 空 → showEmpty。
- 已排除代码 bug：
  - 首页能显示海报 ⇒ 源已加载、type 被正确识别、列表接口可用；若 sourceKey 无效会在 getDetail 第437-438行 NPE，用户未崩溃 ⇒ 传参与切换逻辑正常。
  - getList 与 getDetail 的 type 分支完全一致（都覆盖 0/1/3/4），不存在"列表能拉而详情不支持该 type"的遗漏。
  - 当前项目 detail 解析代码（getDetail/json/xml/checkThunder）与参考项目 D:/Doubao/TVBoxOS_Portrait 逐行一致，未被改坏。
- 根因结论：**龙门影视这个订阅源自身的 detail（详情）接口/蜘蛛返回空或不兼容**，非 App 代码问题、非"订阅源切换"的代码 bug。列表可用 ≠ 详情可用（list 与 detail 是源的两套独立接口）。
- 验证方法（给用户）：抓 logcat 看 SourceViewModel.getDetail 成功分支 `LOG.i(json)` 打印的 detail 响应体；在订阅管理查看龙门影视源的 `type` 字段；用饭太硬/王二小同方式点海报对比是否正常。
- 备注：点海报是否跳 DetailActivity 还是 FastSearchActivity，取决于是否开启 FAST_SEARCH_MODE（GridFragment 207-216 分支），也是排查点之一。

## 修正：真正症状是"首页分栏标签（主页/推荐 my0）显示暂无数据"，非详情页
- 用户澄清：首页分栏里点"首页/主页"那个标签失效显示暂无数据，其他分类标签正常；切换订阅源后同样如此。曾怀疑是"订阅从设置页移到导航栏"的大重构引起。
- 本 session 对 HomeFragment.kt / SourceViewModel.getHomeRecList / DetailActivity / ApiConfig / JarLoader 的排查**全程只读（Grep/Read/diff）**，未改动这些文件。
- 结论（已坐实）：本 session 唯一动了代码的只有 ①版本号 2.5.3（app/build.gradle，commit 3b1f62a）②LiveActivity LoadSir OnHandleListener→Transport（commit ad08ca9）；**两者都不涉及首页标签数据加载**，故不可能造成该现象。
- 用户实测：重置+卸载重装后恢复正常 ⇒ 证实是**本地状态/缓存问题，非代码回归**。原因：TVBox 用 Hawk（SharedPreferences）缓存订阅配置与首页内容；覆盖安装（`adb install -r`）保留旧数据，若旧的首页推荐缓存处于坏/空态、或早前 spThreadPool 自锁残留的 home-rec 后台任务卡死（旧代码），进程不重启就一直空；干净卸载重装清掉旧数据与进程，重新拉取 ⇒ 正常。这也解释了"参考项目一直正常、当前项目有时空"的矛盾——参考项目没背着旧缓存包袱。
