# 2026-10-08

## 重构：设置页「数据备份/还原」改用系统文件选择器(SAF)，弃用「所有文件访问」权限
- 需求：把设置页的数据备份还原改成系统文件选择器方式，不再需要授予 MANAGE_EXTERNAL_STORAGE（所有文件访问）权限。
- 改动文件：
  - `app/src/main/java/com/github/tvbox/osc/ui/activity/SettingActivity.kt`
    - 移除 `llBackup` 里的 `XXPermissions` MANAGE_EXTERNAL_STORAGE 请求逻辑（及 OnPermissionCallback/Permission/XXPermissions 三个 import）。
    - 新增两个 ActivityResultLauncher：`backupSaf`（自定义 ActivityResultContract 包 `ACTION_CREATE_DOCUMENT`，mime=application/zip，带默认文件名 `TVBox-Backup-yyyyMMdd-HHmmss.zip`）、`restoreSaf`（`ActivityResultContracts.OpenDocument`，mime=application/zip+octet-stream）。
    - 新增方法：`doBackupToUri`（在 cacheDir 打 zip 后写入选定 Uri）、`doRestoreFromUri`（从 Uri 读 zip 解包还原）、`restoreHawk`、`buildBackupZip`、`zipFolder`、`unzipTo`。
    - 备份内容 = AppDataManager.backup 导出的 `sqlite` + Hawk2/crypto.KEY_256 导出的 `hawk` JSON，整体打成单个 `.zip`（用 java.util.zip，无需新依赖）。`AppDataManager.backup/restore` 底层文件拷贝逻辑保持不变。
    - `BackupDialog` 改为回调式：`OnActionListener{onBackup(); onRestore()}`，点击后拉起对应 SAF。
  - `app/src/main/java/com/github/tvbox/osc/ui/dialog/BackupDialog.java`：重写为双按钮(立即备份/数据还原)对话框，不再枚举 sdcard/tvbox_backup 本地目录（旧逻辑依赖 MANAGE 权限）。
  - `app/src/main/res/layout/dialog_backup.xml`：布局改为两个按钮（R.id.backupNow / R.id.restoreBtn）+ 提示文案。
  - `app/build.gradle`：versionCode 258 / versionName 2.5.4。
- 未改动：`AndroidManifest.xml` 仍保留 `MANAGE_EXTERNAL_STORAGE` 声明——因 `RemoteServer`(局域网文件服务) 仍在用 `Environment.getExternalStorageDirectory()`，备份/还原已不再请求/使用该权限，但为避免殃及无关功能暂不删声明。若后续也要让文件服务脱离该权限，需单独改 SAF。
- 安全：`unzipTo` 加了 zip 路径穿越校验（canonicalPath 必须落在目标目录内），防恶意 zip。
- 静态自检：全仓无 MANAGE_EXTERNAL_STORAGE / XXPermissions 在备份路径的残留；新符号均交叉引用正确；`R.id.restoreBtn` 已在布局定义。未编译（按约定由用户构建）。
