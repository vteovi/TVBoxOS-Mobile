## 直播页方向重构：取消大屏锁横屏 + 横屏进入不自动全屏（2.17.0 / 314，提交 ccd9067，本地未推送）

### 需求
1. 大屏(平板)横屏进入直播页时被强行锁死横屏 → 要允许转竖屏。
2. 手机横屏点"直播"入口直接变全屏 → 不好, 应停在普通直播页。
3. 保留"竖屏进入直播页 → 转到横屏自动全屏", 但仅限竖屏进入这一路径。

### 根因
- 锁横屏有两处：`LiveActivity.init()` 里 `if (smallestScreenWidthDp>=600) setRequestedOrientation(SENSOR_LANDSCAPE)`；以及 `LiveActivity.override setRequestedOrientation()` 把任何"可能变竖屏"的请求改写成 SENSOR_LANDSCAPE（配套 `isTabletLandscapeLock()`/`mayBecomePortrait()`）。另外 `PlayerTitleView` 标题栏返回按钮在平板下也写死 SENSOR_LANDSCAPE 退出全屏。
- "横屏进入即全屏"的根因是 dkplayer 的 `BaseVideoController.onOrientationChanged()`：一旦 `mOrientationHelper.enable()`，传感器第一次回调报 90/270 度就调 `onOrientationLandscape()` → `startFullScreen()`。之前靠 `setEnableOrientation(!isTabletLandscapeLock())` 只在大屏上关掉，手机上横屏进入必然被弹成全屏。

### 做法
- `LiveActivity`：删除锁横屏三处；`init()` 记录 `mEnteredPortrait = orientation==PORTRAIT`；`setEnableOrientation(true)` 统一开启，用 `controller.setRotateToFullScreenEnabled(mEnteredPortrait)` 作为"是否允许旋转全屏"的闸门；新增 `onConfigurationChanged()`：一旦出现过竖屏就 `setRotateToFullScreenEnabled(true)`（横屏进→转竖屏→再转横屏也能全屏）。
- `LiveNewController`：新增闸门字段 + `setRotateToFullScreenEnabled()`；覆写 `onOrientationLandscape()`/`onOrientationReverseLandscape()`，闸门关闭且当前非全屏时 **只把 requestedOrientation 设回 UNSPECIFIED（不锁横屏、不 startFullScreen）**；覆写 `stopFullScreen()` 用 UNSPECIFIED 代替库里的硬 `PORTRAIT`（否则平板一退全屏就翻竖屏）。
- `PlayerTitleView`：退出全屏按钮统一 UNSPECIFIED（原来平板 SENSOR_LANDSCAPE / 手机 PORTRAIT）。
- 视频区高度自适应 `applyLiveVideoBoxSize()`（布局新增 id `live_video_box`，两套布局都加）：竖屏 `max(240, 屏宽*9/16)`；横屏 `max(240, min(屏高-120, 屏高*0.62))`；同时把 VideoView 高度改 match_parent（原来固定 300dp，大屏偏小）。在 init / onConfigurationChanged / 退出 PiP 时调用，PiP 与全屏时跳过。

### 关键坑（复用价值）
- **dkplayer 的 `onOrientationLandscape/ReverseLandscape` 没有 `if(!mEnableOrientation) return;`**，横屏分支没有开关保护；`onOrientationPortrait` 才有。所以想"只在某些情况自动全屏"必须覆写这两个横屏回调，靠 setEnableOrientation 关不掉。
- **`BoardVideoController.stopFullScreen()` 内部硬编码 `setRequestedOrientation(PORTRAIT)`**，是平板"一退全屏就翻竖屏"的根源，要覆写。
- 传感器回调的 `mOrientation` 记录在 `onOrientationChanged()` 里（跟是否 super 无关），闸门关闭时 mOrientation 仍会被置为 90/270，所以不会反复触发。
- 资源限定符顺序里 smallestWidth 优先于 orientation，因此 `layout-sw600dp` 会盖过 `layout-land`；想给手机横屏单独布局要注意这点（本次改用运行时算高度，避免再加一套布局）。
