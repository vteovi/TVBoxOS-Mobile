- **运行崩溃修复（LiveActivity NPE @ init:245）**：2.14.1 release 装到 sw>=600 设备（Xiaomi 22081283C 报告）启动即崩：`findViewById(R.id.ic_pip)` 返回 null → `ImageView.setVisibility` NPE。根因：`layout-sw600dp/activity_live.xml` 当初加 PiP 时**漏加 `ic_pip`**（只有 `ic_cast`/`ic_setting`），而代码 `init()` 无条件期望该视图存在；手机端 `layout/activity_live.xml` 有 `ic_pip` 故不崩，平板/sw>=600 命中 sw600dp 布局才崩。修法：① sw600dp 布局补 `ic_pip`（顺序对齐手机端 `ic_live_source→ic_pip→ic_cast→ic_setting`）；② `init()` 对 `icPip` 加 null 保护（防御任何变体缺视图）。版本号升到 **2.14.2 / versionCode 300**，update.json 同步。提交 4301baf（本地未推送）。

- **画中画白条修复（进入 PiP 顶部有白色标题栏）**：用户反馈直播页进画中画后不是纯画面、顶部有白色标题栏。根因：`enterPip()` 只设了 `setAspectRatio`/`setActions`，没设 `setSourceRectHint`，系统默认把整个 Activity 窗口（含顶栏）缩进 PiP。修法：用视频播放视图（`LiveActivity.mVideoView` / `DetailActivity.playFragment.getPlayer()`）的 `getLocationInWindow` + 宽高构造 `Rect`，传给 `setSourceRectHint`，使 PiP 只截取视频区域。两个页面同源修复。版本号升到 **2.14.3 / versionCode 301**，update.json 同步。提交 67fdfd4（本地未推送）。

- **直播画中画三连修（2.14.4 / 302，提交 afa6f2a）**：用户进一步反馈：① 小窗仍有白条；② 要"应用外"画中画（和点播一致），不是应用内窗口；③ 点关闭按钮后仍在播声音。
  - 根因：直播页进 PiP 没有像点播那样先把界面切"纯视频全屏"，于是小窗混入了 240dp 视频区 + 下方 EPG/频道列表等白底 UI；且关闭 PiP 时 Activity 早已是 paused 状态、`onPause` 守卫(`!isInPiP`)不再触发，所以 audio 不停。
  - 修法（对齐点播 `DetailActivity`）：
    * `enterPip()` 进 PiP 前调 `applyPipUiMode(true)`：隐藏频道列表/EPG/底部导航/源切换等控件，视频容器与播放器 `MATCH_PARENT` 铺满窗口（保存原 LayoutParams 与子控件可见性以便还原）；再 `startActivity(HOME)` 模拟回桌面让画中画悬浮在应用外；再 `enterPictureInPictureMode`。
    * `onPictureInPictureModeChanged`：进 PiP 切纯视频 UI，出 PiP `applyPipUiMode(false)` 还原，并置 `mPipClosing=true`。
    * 关闭判定：新增 `onStop()`，当 `mPipClosing && !isInPiP` → `mVideoView.pause()` + `finish()`（展开时会先走 `onResume` 把 `mPipClosing` 复位，不误杀）。另 `onResume` 复位 `mPipClosing=false`。
  - 新增成员 `mPipClosing/mPipUiMode/mSavedVis/mSavedVideoLp/mSavedParentLp` 与 `applyPipUiMode()/setGone()` 辅助方法；补 `import android.widget.RelativeLayout`；新增 `onStop`。
  - ⚠️ 教训：PiP 的**实际内容**是 Activity 布局被缩放重排后的样子（sourceRectHint 只影响进入动画），要让小窗干净必须进 PiP 时把其它 UI 都隐藏、视频铺满；且"关闭按钮"靠 `onStop` 而非 `onPause` 处理。
