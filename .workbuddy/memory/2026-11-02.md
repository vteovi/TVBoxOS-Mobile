# 2026-11-02

## 搜索页新增「卡片 / 列表」显示方式切换（v2.27.0 / versionCode 345）
- 用户需求：2.26.3 把搜索结果统一成海报卡片后，仍要保留旧的「左图右文列表」；搜索页加切换按钮，并且**记住选择**。
- 实现要点：
  - `FastSearchAdapter` 改为**多布局**：构造传 `super(0, data)`，覆写 `getDefItemViewType(position)`（**不是** `getItemViewType`，后者已被库用于 header/footer 分发，覆写会破坏），`onCreateDefViewHolder(parent, viewType)` 里 `createBaseViewHolder(parent, layoutId)` 选 `item_search_card` / `item_search`。
  - BRVAH 版本 `2.9.45-androidx`：javap 确认 `getDefItemViewType(int)`、`onCreateDefViewHolder`、`createBaseViewHolder(ViewGroup,int)` 均存在；`BaseViewHolder` **没有** `getItemViewType()/getLayoutId()`，convert 里只能用适配器自己的 `cardMode` 字段判断。
  - 切模式必须 `notifyDataSetChanged()`：viewType 变了，RecyclerView 才会按新布局重建 holder。
  - `FastSearchActivity`：`newResultLayoutManager()` 卡片→`GridLayoutManager(getPosterSpanCount())`，列表→`LinearLayoutManager`；切换时两个 RecyclerView（全部结果 / 按源过滤）同时换 LM + 两个 adapter 同时 setCardMode。
  - 持久化 `HawkConfig.SEARCH_CARD_MODE`（Boolean，默认 true 卡片），并加进 `BackupManager` 的备份键列表。
  - 图标 `ic_view_grid.xml` / `ic_view_list.xml`（Material view_module / view_list path），按钮显示"点一下会切到的模式"。
- 列表模式图片沿用旧实现：`RoundTransformation(MD5(url)).centerCorp(true).override(110dp,160dp).roundRadius(20dp, ALL)`（旧代码 key 里带 position 会导致缓存抖动，改成只用 url）。
- 版本按规则升 MINOR：2.26.7 → **2.27.0 / 345**。
