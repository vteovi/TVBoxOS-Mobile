## 搜索页列表模式缩略图跟随「横版海报」设置（v2.27.1 / versionCode 346）
- 需求：设置里开启「横版海报」后，搜索页**列表显示模式**的缩略图也要是 16:9，而不是固定竖版。
- `item_search.xml` 原来根高固定 120dp、ImageView `weight=3 / match_parent`（约 102x120），图片实际按 110x160 裁剪后 fitCenter，两边有留白。
- 改法：
  - 布局：根 `layout_height=wrap_content` + `gravity=center_vertical`；ImageView 固定 80x120dp（默认竖版）+ `scaleType=centerCrop`；文字区 `weight=1`、`wrap_content`，并加 id `llText` 供代码调留白。
  - `FastSearchAdapter`：新增 `landscapeCard = Hawk.get(HawkConfig.LANDSCAPE_CARD, false)`（构造时读一次，搜索页每次进都会重建适配器）；列表模式按 setting 把 ImageView 设为 80x120（竖版 2:3）或 160x90（横版 16:9），跟随调整 `llText` 上下 padding（12/2dp）与 `tvNote` 上间距（20/6dp）。
  - 裁剪 `RoundTransformation.override(w,h)` 用与 ImageView 相同的 dp2px 值；**缓存 key 改为 MD5(url + "@" + w + "x" + h)** —— 否则切了比例会命中旧尺寸位图。
  - 圆角随比例：竖版 20dp / 横版 14dp。
- 卡片模式不用改：`RatioShadowLayout` 本来就按 LANDSCAPE_CARD 自动切比例。
- 注意：`item_search.xml` 还被**死代码** `SearchAdapter.java`（无任何引用）使用；`QuickSearchAdapter` 用的是 `item_quick_search_lite`，不受影响。
