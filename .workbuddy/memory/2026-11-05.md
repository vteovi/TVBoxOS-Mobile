# 2026-11-05

## v2.29.1 修复：系统深色 + 软件浅色时直播页白底白字

现象（用户报 + 截图）：手机系统开深色模式，软件内设成浅色模式，进直播页后频道列表大部分文字消失，只剩"选中态"的蓝色按钮可见。

根因（已用 javap 反编译确认）：`com.blankj.utilcode.util.ColorUtils.getColor(int)` 的实现是
`ContextCompat.getColor(Utils.getApp(), id)` —— 用的是 **Application** 的 Resources。
- AppCompat 的 `setDefaultNightMode` 只把浅/深覆盖应用到 **Activity** 的 Resources；
- Application 的 `configuration.uiMode` 始终是「系统」值（NIGHT_YES）；
- 于是 `values-night` 的 `text_foreground=#FFFFFF` 被取到，而 item 背景（`bg_transparent` 叠在父容器 `bg_gray=#80FFFFFF` 上）按 Activity 解析成浅色 → **白底白字**。

修复：
- `Utils.getThemeColor(context, resId)` 新增，统一用调用方 Context（Activity / Dialog 的 ContextThemeWrapper）解析颜色；
- 替换 12 处 `ColorUtils.getColor`：LiveChannelGroupNewAdapter / LiveChannelItemNewAdapter / LiveSettingGroupAdapter / LiveSettingItemAdapter（用 `mContext`）、PlayingControlDialog / PlayingControlRightDialog（用 `getContext()`）、PlayFragment（用 `requireContext()`）、MyBatteryView.kt（用 `context`）；
- `Utils.isDarkTheme()` 改为优先 `AppCompatDelegate.getDefaultNightMode()`（YES→true / NO→false / 其它才读系统 uiMode）。原来系统深色+软件浅色会误判成深色 → XPopup 弹窗按深色渲染、`statusBarDarkFont(!isDarkTheme())` 把浅色状态栏设成白图标；
- 顺带修 `LiveEpgAdapter` 里硬编码的 `Color.WHITE`（EPG 浅底上白字）和 `LiveEpgDateAdapter` 的 `color_CCFFFFFF` → `text_sub_foreground`。这两个 adapter 当前没被 new（死代码），修它是防以后启用踩坑。

版本 2.29.0(358) → **2.29.1(359)**，`compileArm64v8DebugJavaWithJavac` + `compileArm64v8DebugKotlin` 均 BUILD SUCCESSFUL。
分支：按新约定提交在 **dev**（`86ef785`），未推送，等用户验证后说"发布"再合并 main + 打 tag。

经验：排查这类"颜色不对"的问题，先分清**资源是按哪个 Context 的 configuration 解析的**。Activity 的 Resources 受 AppCompat 控制，Application 的不受。
