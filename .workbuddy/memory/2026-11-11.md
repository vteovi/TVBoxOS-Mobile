## v2.32.8 修复 DetailActivity 销毁时 NPE 闪退

用户贴的是线上崩溃日志（v2.32.7 / Android 16 SDK36 / 小米）：`RuntimeException: Unable to destroy activity {DetailActivity}`，
cause 是 `Attempt to invoke virtual method 'boolean MyVideoView.isPlaying()' on a null object reference`，
栈顶 `DetailActivity.registerActionReceiver(DetailActivity.java:1369)` ← `onDestroy(1102)`。

**成因**：`onDestroy()` 第一行就调 `registerActionReceiver(false)`（本意是注销后台播放广播），
而该方法 `else` 分支末尾为了「退出画中画时暂停播放」，直接写 `playFragment.getPlayer().isPlaying()`。
- `PlayFragment.getPlayer()` 返回 `mVideoView`，而 `mVideoView` 在 `PlayFragment.onDestroyView()` 里被 `release()` 后**显式置 null**；
- `playFragment` 只在 `showPreview==true` 时才 `new`，且是 `commit()` 异步事务 → 页面快速返回时视图可能从未创建；
- `onResume()` 里 `playServerSwitch(false)` → `registerActionReceiver(false)` 也走同一条路，旋转/分屏同样会撞。
结果：Activity 销毁过程中抛异常，被 `performDestroyActivity` 包成 RuntimeException 直接闪退。

**改法**（`DetailActivity`）：
1. `registerActionReceiver(false)`：`playFragment != null && getPlayer() != null && getController() != null && isPlaying()` 全判空；
2. `onDestroy()` 里 `registerActionReceiver(false)`、`unregisterReceiver(mBatteryReceiver)`、`unregisterReceiver(mHomeKeyReceiver)` 全部 try/catch——
   页面异常提前结束时接收器可能没注册成功，重复注销抛 `IllegalArgumentException`，一样在销毁阶段崩溃；
3. 后台播放广播 `onReceive` 补 `playFragment` 判空（别的 Activity 已销毁后点通知会 NPE）；
4. `enterPip()` 入口先判断 `playFragment/getPlayer/getController` 是否就绪（否则 Toast「播放器尚未就绪」直接返回），
   400ms 延时任务执行前再确认一次（页面可能已销毁）。
